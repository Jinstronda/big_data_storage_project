Big Data Storage final project, MongoDB commands for group_11

Database and collection
use group_11;

Restore BSON backup from the submitted zip root
mongorestore --db group_11 --collection sales_receipts --drop group_11.bson

Restore from this workspace, before zipping
mongorestore --db group_11 --collection sales_receipts --drop deliverables/group_11.bson

Full dump style restore, if using the support dump folder
mongorestore --drop support/dump

After restore, run the validator and index commands below if Compass or mongorestore did not apply metadata automatically. Then verify the load.
db.sales_receipts.countDocuments();
db.getCollectionInfos({ name: "sales_receipts" });
db.sales_receipts.getIndexes();

Indexes
db.sales_receipts.createIndex({"sale_datetime": 1}, { name: "idx_sale_datetime" });
db.sales_receipts.createIndex({"branch.code": 1, "sale_datetime": 1}, { name: "idx_branch_date" });
db.sales_receipts.createIndex({"items.product_line": 1, "financials.total": -1}, { name: "idx_product_total" });
db.sales_receipts.createIndex({"payment.method": 1, "sale_datetime": 1}, { name: "idx_payment_date" });
db.sales_receipts.createIndex({"customer.type": 1, "items.product_line": 1, "rating": -1}, { name: "idx_customer_product_rating" });
db.sales_receipts.createIndex({"rating": 1, "financials.total": -1}, { name: "idx_rating_total" });
db.sales_receipts.createIndex({"sale_hour": 1}, { name: "idx_hour" });

Simple insight queries

1. March receipts for branch C, sorted by highest ticket value.
db.sales_receipts.find(
  { "branch.code": "C", sale_datetime: { $gte: ISODate("2019-03-01T00:00:00Z"), $lt: ISODate("2019-04-01T00:00:00Z") } },
  { invoice_id: 1, branch: 1, sale_datetime: 1, "financials.total": 1, rating: 1 }
).sort({ "financials.total": -1 }).limit(10);

Aggregation pipelines

A. Revenue, profit, tickets, and rating by branch.
db.sales_receipts.aggregate([
  { $group: { _id: "$branch.code", city: { $first: "$branch.city" }, tickets: { $sum: 1 }, revenue: { $sum: "$financials.total" }, gross_income: { $sum: "$financials.gross_income" }, avg_rating: { $avg: "$rating" } } },
  { $sort: { revenue: -1 } }
]);
Checked output:
C | $110,568.71 | 328 tickets | avg rating 7.07
A | $106,200.37 | 340 tickets | avg rating 7.03
B | $106,197.67 | 332 tickets | avg rating 6.82

B. Product line performance.
db.sales_receipts.aggregate([
  { $unwind: "$items" },
  { $group: { _id: "$items.product_line", units: { $sum: "$items.quantity" }, revenue: { $sum: "$items.line_total" }, gross_income: { $sum: "$items.gross_income" }, avg_rating: { $avg: "$rating" } } },
  { $sort: { revenue: -1 } }
]);
Checked output:
Food and beverages | $56,144.84 | 174 tickets | avg rating 7.11
Sports and travel | $55,122.83 | 166 tickets | avg rating 6.92
Electronic accessories | $54,337.53 | 170 tickets | avg rating 6.92
Fashion accessories | $54,305.89 | 178 tickets | avg rating 7.03

C. Sales by hour of day.
db.sales_receipts.aggregate([

  { $sort: { revenue: -1 } }
]);

Index impact on this 1000 document course dataset
1. Branch C in March: full scan checks 1000 documents. The branch plus date index narrows the candidate set to about 106 receipts.
2. High value Food and beverages: full scan checks 1000 documents. The product plus total index starts from 174 Food and beverages receipts and returns 37 receipts above 500.
3. Cash above average ticket: full scan checks 1000 documents. The payment plus date index starts from 344 cash receipts and returns 142 receipts above the average ticket.
4. Member Sports and travel: full scan checks 1000 documents. The customer plus product plus rating index starts from 87 matching loyalty receipts and can also serve the rating sort.
5. Low rating follow up: full scan checks 1000 documents. The rating plus total index starts from 153 low rating receipts and can serve the follow up sort.
